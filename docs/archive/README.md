# Historical Archive

This directory holds historical project artifacts that are no longer current but
are kept for reference: completion summaries, hardening PR notes, and similar
one-off records from past waves and milestones.

## What lives here

- Completion summaries from finished waves and milestones
- Hardening / security PR notes that have already been merged
- Other point-in-time records that are useful for archaeology but not for
  day-to-day development

## What does NOT live here

- Current documentation — see the top-level [`docs/`](../) directory
- Setup, build, and test instructions — see the repository root `README.md`
- Anything that is still referenced by code, CI, or active docs

## Status

Everything in this directory is **historical**. It is not maintained, may
reference removed code or outdated workflows, and should not be treated as a
source of truth. If you need current guidance, start from the repository root
`README.md` and the top-level `docs/` directory.
